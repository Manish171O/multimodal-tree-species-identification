Adaptive quality-aware multimodal fusion for tree species identification

The model learns how much to trust each airborne sensor for each tree. It keeps working when a sensor is missing, and it is always scored on sites it never saw in training (MLBS, STEI, WREF; 423 crowns).

Synthetic data. No real NEON file was available, so every number here comes from a generated dataset with a NEON Multi-Modal Tree Crown–like layout: long-tailed species, look-alike genera, per-site illumination shifts, missing and degraded sensors. The numbers show that the pipeline works and how its parts interact. They are not real-world accuracy.

What the experiments show

  • Fixed
    Cross-site spectral shift was the main failure. In the baseline, removing HSI raised test accuracy from 0.693 to 0.747, because the hyperspectral branch had learned each site's brightness and calibration. Training with random spectral gain, tilt and offset, plus RGB brightness jitter, lifts validation macro-F1 from 0.372 to 0.559 and test accuracy by 15 points. HSI-only accuracy doubles.
  • Works
    Modality dropout is what makes missing sensors survivable. Without it, accuracy with one sensor missing falls 3.3 points, macro-F1 falls 5.1 points, and LiDAR-only accuracy falls from 0.567 to 0.461. The cost is slightly worse calibration with all sensors present (ECE 0.066 vs 0.041).
  • Mixed
    Trust scores are informative but did not raise accuracy here. Trust spots hazy HSI almost perfectly (AUROC 0.99) and cuts the weight on noisy RGB or HSI from about 0.34 to 0.20 and 0.15. It misses blurred RGB and sparse LiDAR. Across three seeds, plain masked-mean fusion scores the same: test accuracy 0.849 ± 0.009 with trust vs 0.848 ± 0.021 without.
  • No effect
    The cross-modal contrastive loss made no measurable difference (validation macro-F1 changed by +0.007 without it, well inside seed noise).
  • Limit
    The long tail and open set set the ceiling. Every species with at least 10 training crowns reaches test F1 ≥ 0.67. The 17 test species absent from the training sites score 0 by construction, which is why results are also reported on seen species (accuracy 0.925).

Variants and model selection

The Phase-5 evaluation found that the hyperspectral branch did not transfer to new sites: removing HSI raised test accuracy. Two fixes were trained and the final model was chosen on validation macro-F1, so the test sites played no part in the choice.

Final model diagnostics

Accuracy on species seen at the training sites: 0.925. Auxiliary structure head: height MAE 1.74 m (R² 0.93), crown diameter MAE 0.31 m (R² 0.98).

Method

Three encodersRGB residual CNN · HSI band compression + spatial conv + 1-D spectral CNN · LiDAR masked PointNet with height quantiles. 128-d each.
Evidential trustOne Dirichlet head per sensor; trust = 1 − C/Σα, set to 0 when the sensor is missing.
Adaptive fusionw ∝ mask · (trust + ε), with cross-modal InfoNCE pulling the same tree's embeddings together.
Heads and loss167-way focal loss with class-balanced sampling, height and crown regression, modality dropout during training.

Reproduce

pip install -r requirements.txt
python -m pytest -v                  # 98 tests, ~45 s on CPU, includes a 2-epoch smoke test
python scripts/run_experiments.py    # data → variants → selection on val → ablations → seeds → report
python scripts/evaluate.py --checkpoint outputs/experiments/spectral_aug/best.pt
  • Seeds are fixed and data order, augmentation and modality dropout are seeded per sample, so a retrained baseline matches the original to the last digit.
  • The split holds out whole sites. 17 test species never occur at the training sites, so results are also reported on seen species only.
  • Limitations: synthetic data, a cross-site augmentation family that matches the simulated shift (so its gain here is an upper bound), and three seeds only for the key comparison.
